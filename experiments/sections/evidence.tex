The final package is rebuilt by {\small\texttt{scripts/\allowbreak{}recon/\allowbreak{}final\_\allowbreak{}package.\allowbreak{}py}} from saved CSV rows without running reconstruction. Its master table contains 70 conditions, each with eight test subvolumes. This document rounds selected means for readability; full precision, subvolume variation, repeat counts and per-condition source files remain in the CSVs. Original figure labels such as ``paper PnP'' identify the generic-prior solver, not a request to update the main manuscript; the extended controls use the validation protocol stated here.

Software recorded for the final server runs was SCICO 0.0.6, JAX 0.4.35, PyTorch 2.7.1+cu118 and Python 3.10.10. After a CUDA fault during concurrent work, the remaining runs used a serial GPU queue. No new experiment or remote job was launched to prepare this document.

\subsection{Corrections that should not be lost}

Earlier headings marked ``active'' can describe superseded architecture choices; the one-plate final state takes precedence over the initial two-layer default. Pre-vectorial and sub-feature-scale headline scores are historical and are not final evidence. Old field-statistics proxy claims of an optimal random plate are narrower than the later detector-aware results. The final GPnP summary excludes showcase crops and replaces older ten-crop averages. Different three-realisation, five-subset and detector-study tables should not be merged into one apparent condition. Crop p576's residual training overlap remains documented, even though exclusion and cross-domain controls support the learned-prior conclusion.
