\section{What the measurements establish}
\label{sec:structural}

A reconstruction is one volume that explains the images under a prior. For relational questions, such as whether a dendrite reaches a soma, we also ask whether \emph{every} volume that explains the images agrees.

\paragraph{Consistency set and connectivity query.}
Given measurements $\by\in\R^M$ from $k$ directions and per-row intervals $[\ell_i,h_i]$ that contain the noise-free measurement with stated probability, the measurement-consistency set is
\begin{equation}
\C(\by)=\{\bx\in[0,1]^N:\ \ell_i\le(\bA\bx)_i\le h_i,\ i=1,\dots,M\},
\label{eq:cset}
\end{equation}
where the box is the reconstruction's intensity normalisation. For calibrated Gaussian noise we use the Bonferroni box $y_i\pm z\sigma$ with $z=\Phi^{-1}(1-\alpha/2M)$, $\alpha=0.05$, so that $\bx_{\mathrm{gt}}\in\C(\by)$ with probability at least $0.95$ under the noise model. In a query region with 6-adjacency, a voxel is active if $x_v\ge\tau$, and $p,q$ are connected if an active path joins them; equivalently the bottleneck $b(\bx)=\max_{P:p\to q}\min_{v\in P}x_v\ge\tau$. The query is \emph{certified connected} if $\min_{\C}b\ge\tau$, \emph{certified disconnected} if $\max_{\C}b<\tau$, and \emph{ambiguous} otherwise. Ambiguity is proven by exhibiting two volumes in $\C(\by)$ with opposite connectivity, both re-checked independently of the optimiser (unscaled residual, breadth-first search and union--find). Problems that a solver cannot decide within its budget are reported as undecided, never as ambiguous.

\paragraph{Computation.}
Per-voxel bounds $L_v=\min_{\C}x_v$, $U_v=\max_{\C}x_v$ (two linear programs per voxel) certify the query when the voxels with $L_v\ge\tau$ already connect $p,q$, or those with $U_v\ge\tau$ do not. Otherwise mixed-integer programs with separator and flow encodings search for the two witnesses, and a joint verifier bounds $\min b$ and $\max b$ exactly. These encodings are standard; formulations, tolerances and validation are in the supplement. A certificate is a statement about all volumes allowed by the stated noise and object model, computed in floating point with independent re-checks; it is not a formal proof, and it does not hold for objects or errors outside the model.
