\section{Reconstruction with fixed optics}
\label{sec:s:reconstruction}

We first reconstruct with total variation (TV), which requires no trained denoiser. We then change the prior to test whether the optical gain persists under plug-and-play (PnP) reconstruction. Main Figure~3 shows the reconstruction routes. All three iterative methods use the measurements $\mathbf y$ and the forward matrix $\mathbf A$ of the plate being tested. The denoisers stay fixed across plates. We select scalar parameters separately for each plate and acquisition condition by mean peak signal-to-noise ratio (PSNR) on two held-out vascular crops.

\paragraph{Common data update.}
The alternating direction method of multipliers (ADMM) alternates fitting the images with applying the chosen prior. At iteration $n$, let $\mathbf v_j$ be the auxiliary variable for operation $j$, $\mathbf d_j$ its scaled dual variable, $\beta_j>0$ its penalty, and $K_j$ the linear map on which that operation acts. Given its update function $\mathcal F_j$, the steps are
\begin{align}
\mathbf x^{n+1}&=\arg\min_{\mathbf x}
\Big\{\tfrac12\|\mathbf A\mathbf x-\mathbf y\|_2^2\notag\\
&\qquad+\sum_j\tfrac{\beta_j}{2}\|K_j\mathbf x-\mathbf v_j^n+\mathbf d_j^n\|_2^2\Big\},
\notag\\[-2pt]
\mathbf v_j^{n+1}&=\mathcal F_j(K_j\mathbf x^{n+1}+\mathbf d_j^n),\\
\mathbf d_j^{n+1}&=\mathbf d_j^n+K_j\mathbf x^{n+1}-\mathbf v_j^{n+1}.\notag
\end{align}
We initialize by back-projecting the images and normalizing by the largest voxel value. TV also clips this initial estimate to $[0,1]$. At each data update we use up to 20 conjugate-gradient steps with relative tolerance $10^{-5}$.

\paragraph{TV.}
The two maps are the 3D forward-difference gradient and the identity, both with unit ADMM penalty. The gradient update shrinks each voxel's gradient vector by vector soft thresholding with weight $\lambda_{\rm TV}$. The identity update projects intensities onto $[0,1]$. We run 300 ADMM iterations and clip the final volume to this interval. We choose $\lambda_{\rm TV}$ from $\{0.01,0.03,0.1,0.3,1,3\}$. If the best value is at an endpoint, we extend that end by a factor of three, at most twice. All five designs select 0.1 at eightfold measurement compression ($C=8$).

\paragraph{PnP.}
The PnP maps $K_j$ are identities. The pretrained prior applies the same 17-layer natural-image denoiser (SCICO DnCNN 17M) independently to slices in the $xy$, $xz$ and $yz$ orientations \cite{zhang2017,balke2022scico}. The neuron-trained prior uses a neuronal 2D denoiser for the same slices and adds a 3D denoiser. Thus changing between these priors changes both architecture and training data.

Both PnP methods run 20 ADMM iterations and clip the final volume to $[0,1]$. A scalar $s$ sets the penalty $5s$ on each denoising update. The nominal weights are 0.2 for the slice denoisers and 1 for the 3D denoiser. These networks apply the same learned function for any positive weight. An optional voxelwise $\ell_1$ penalty of weight $0.2l$ uses scalar soft thresholding with ADMM penalty $10s$. We omit it when $l=0$. We validate $s\in\{2^{-4},2^{-3},\ldots,4\}$ and $l\in\{0,1/16\}$, extending a boundary scale by two and the nonzero sparsity weight by four, at most twice. Every selected value of $s$ lies in the interior of the final grid. At $C=8$, pretrained PnP uses $s=0.25$, $l=0$ for every design. Neuron-trained PnP uses $s=0.125$ for the untrained plate and $0.25$ for each trained plate. Only the seed-0 Fisher plate uses $l=1/16$.

\paragraph{Training the neuronal denoisers.}
The 2D network has 17 layers with 64 channels and the 3D network has 12 layers with 48 channels. We use 459 crops from stacks 8 and 9 of SOM009 cell 1 and hold out stack 10 for monitoring. Before cropping, we exclude duplicate planes and planes whose mean intensity falls below half their neighbors' median. We add Gaussian noise with standard deviation sampled uniformly from 0 to 0.25 and augment by flips, lateral transposition and intensity scaling in $[0.3,1]$. Both networks use Adam at $10^{-3}$. The 2D network takes 30,000 updates on random slices at batch size 64. The 3D network takes 15,000 on volumes at batch size 8. Neither network uses test data or a specimen-specific noise estimate.
