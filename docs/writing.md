# Writing

- Lead each paragraph with its scientific point. Prefer direct verbs and short sentences.
- Explain the imaging idea before implementation details. Put numerical settings in Experimental Setup.
- Keep simulation findings distinct from experimental validation and proposed future work.
- Distinguish reconstruction accuracy from what the measurements uniquely determine.
- Report compression as the number of reconstructed values divided by scalar measurements.
- Name the evaluated decoder, specimen set and comparison baseline where needed for interpretation.
- Treat crops from one cell as correlated observations; retain the stated statistical assumptions.
- Use LaTeX citation and cross-reference commands rather than manually numbered references.
- Edit the section sources and tables, then rebuild the reading PDFs. Keep figure labels and units consistent.
